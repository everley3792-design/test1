# Roadmap

穩定版本：**v4.2（存檔版本 42）**。第二階段從這個版本繼續。

## 第一階段（v4.0 – v4.2）已完成

- 單一 Canvas 的 2.5D 世界、分層角色動畫、生活模擬 AI、社交與負面事件、多地點、房屋與家具。
- 工坊（繪圖、物品／家具／建築／飾品、動畫工作室、作品包匯出入）、自訂事件、電影式互動。
- Android：WebView 主 App、系統級懸浮桌寵（前景服務、原生繪製、App 感知）。
- **v4.2 整合**
  - 存檔驗證、修復、版本遷移。
  - 每日快照與損毀復原。
  - 完整備份（含所有圖片與影格）與角色包。
  - 效能選項全部實際生效。
  - 面板就地更新（不閃爍）、對話泡泡避讓。
  - 橋接信任檢查、桌寵位置記憶、透明區域不攔截觸控。
  - 自動化測試（`tools/check.mjs`、`tests/e2e.cjs`）。

## 需要實機驗證（目前只完成編譯）

- [ ] 懸浮桌寵顯示在其他 App 上方：各廠牌（Samsung One UI、小米 HyperOS、OPPO ColorOS）。
- [ ] 觸控視窗只蓋住身體：確認身體外的透明區域可以點到底下的 App，拖曳、甩出、長按選單正常。
- [ ] 位置記憶：放下後關閉、重開桌寵，以及旋轉螢幕之後。
- [ ] 從背景啟動被拒時（Android 12+），服務安全結束，下次開 App 再出現。
- [ ] 撤銷懸浮視窗權限後服務自動停止；通知權限被拒時桌寵仍可顯示。
- [ ] 省電策略會殺服務的機型：引導使用者把 App 加入白名單。
- [ ] WebView 在低階機的實際 FPS 與耗電（目前數據來自桌機 Chromium）。

## 第二階段建議順序

1. **實機測試與修正**：上面的清單。
2. **桌寵與主 App 的資料同步**
   - `pets.json` 加上 schema 版本。
   - 顯示最後同步時間。
   - App 關閉期間的互動在下次開啟時補記錄（已有事件佇列）。
3. **音效與環境音**：要有音量與靜音設定，並遵守省電模式。
4. **迷你遊戲**：玩家操作的釣魚、捕蟲、園藝。
5. **更多地點與節慶活動**：圖書館、活動中心、季節祭典。
6. **服裝自由擺放**：飾品拖曳定位，取代目前的滑桿。
7. **多人聚會對話**：3 人以上的話題鏈。
8. **雲端備份（選用）**：目前只有本機檔案與分享。

## 已知限制

- 點選場景物件用矩形判定。物件互相遮擋時，點到的是前面的物件（例如屋內的床擋住門的下半部時，要點門的上半部）。
- 3.2 的自製物品只依名稱對應到內建物品。3.2 的工坊圖片沒有自動轉成 v4 工坊作品。
- 效能數據是在 Chromium headless 量的，不代表手機 WebView。
