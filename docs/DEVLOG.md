## v4.0（本次 Session）

### 為什麼重建畫面層，而不是繼續修補 3.2

3.2 版是單一 1.4 MB 的 HTML，裡面有 37 個 `<style>` 和 31 個 `<script>`，每一版都用新的補丁覆寫舊的。
實際量測（Playwright，390×844，5 秒）找出閃爍、破圖、掉幀的根本原因：

| 量測項目 | 3.2 版 | v4 |
|---|---|---|
| 5 秒內 DOM 變動次數 | **5,954**（`a-shadow`、`cd`、`actor` 的 style 每秒被改寫數百次） | **1～2** |
| DOM 節點數 | 6,588 | 264 |
| 同時執行的動畫迴圈 | ≥ 3 個 rAF 迴圈 + 49 個 setInterval 寫入同一批元素 | 1 個 rAF 迴圈 |
| `backdrop-filter` | 63 處（Android WebView 破圖主因之一） | 0 |
| `!important` 覆寫 | 440 | 4（隱藏狀態、減少動態） |
| 每格渲染時間 | — | 約 0.3～0.6 ms（headless 量測） |

多個迴圈同時改寫同一個角色的 transform／CSS 變數，加上大量合成圖層（backdrop-filter、will-change、
濾鏡），在 Android WebView 上會出現圖層閃爍、貼圖遺失（破圖）與掉幀。只靠再加 CSS 覆寫無法根治，
所以 v4 改為：**世界、角色、天氣、光影、對話泡泡全部畫在單一 Canvas，DOM 只放靜態 UI，且只在資料改變時更新。**

遊戲資料與既有成果保留：
- 3.2 的原創 Low-Poly 貓咪造型產生器（`ocSVG`）原封不動移植到 `web/src/art/cat-svg.js`，既有角色外觀不變。
- 3.2 的性格滑桿、67 個特質、10 類小怪癖、16 種性格類型與台詞，原樣移植到 `web/src/sim/legacy-data.js`。
- 舊存檔（`ocs.v1`、`ocs.eco.v1`、`ocs.items.v1`、IndexedDB `oc-shimeji`）啟動時自動匯入，**不刪除舊資料**。
- `legacy/oc-shimeji-3_2-smooth.html` 保留原始檔作為參考。

### 本次完成

1. **閃爍／破圖／卡頓**：見上表。另外修正 3.2 造型中「側背包」配件多一個 `</g>` 的錯誤（舊版靠 HTML 容錯沒發現）。
2. **摸摸改為在角色身上上下滑動**：每次滑動方向反轉算一下，角色會瞇眼、頭跟著手傾斜、尾巴快速擺動、冒愛心；
   長按抱起移動、放開會落地擠壓；點一下打招呼並開啟行動選單。Android 桌寵使用同樣的手勢。
3. **角色動畫重做**（`web/src/art/rig.js`）：把貓咪 SVG 拆成尾巴、左右腳、身體、11 種表情的頭部圖層，以彈簧系統驅動
   呼吸、眨眼（偶爾連眨）、走路步伐（腳交替抬起）、重心起伏、頭部延遲跟隨、尾巴擺動、轉身擠壓、跳躍伸展與落地擠壓、
   睡覺、坐下、吃東西（食物逐漸變小）、被抱起（腳晃動）、生氣、難過、說話嘴型。走路方式、睡相、開心反應等小怪癖會改變動畫。
4. **UX**：精簡 HUD（左上角色、右上星幣＋唯一的時間天氣元件、右下三個快捷鍵）、可拖曳的快捷背包（拖物品到角色身上）、
   五個底部導覽（小島／角色／地圖／日常／設定），所有視窗只做 transform／opacity 動畫。
5. **閃爍**：同第 1 點；頁面打開時暫停世界繪製，回到世界才恢復。
6. **家**：開場可選三種房子（紅瓦石牆小屋、藍頂原木屋、白牆花園屋），拖曳擺放在小島（綠色＝可放），房子落地演出；
   屋內有床、餐桌、小廚房、書櫃、地毯、立燈、植物、沙發，角色會自己去睡覺、做飯、吃飯、看書、窩沙發、洗澡。
   之後可在「日常 → 家與佈置」搬家、換房子、擺放在商店買的家具。
7. **美術**：Breath of the Wild／Animal Crossing 方向的療癒 Low-Poly 小世界：多面體樹木與岩石、2.5D 立體懸崖與草地厚度、
   空氣透視霧氣、滾筒世界地平線、雲朵與雲影、晝夜色調與夜間燈光、營火、炊煙、噴水池、花瓣、螢火蟲、雨雪。
8. **更聰明、更有深度的生活模擬**：
   - 效用 AI：依需求缺口、特質、時段、天氣、地點記憶、願望與作息（夜貓子／早起）選擇行動，會跨地點旅行。
   - 社交：打招呼、聊天（天氣、時間、地點、共同回憶話題）、開玩笑、稱讚、分享興趣、玩鬼抓人、安慰、送禮、戀愛。
   - **負面經歷**：拌嘴、誤會、大吵（之後互相迴避）、**絕交**（需玩家選擇：讓它發生／調解／冷靜一下），道歉與和好、
     **生病**（感冒、肚子痛、過度疲勞、心情低落；可用熱湯、藥、休息、摸摸、朋友照顧治療）、跌倒、做惡夢、淋雨、吃醋。
   - 記憶影響之後的選擇與對話；後天特質成長一定先詢問玩家（接受／稍後／拒絕／鎖定／關閉建議）。

### Android（`android/`）

- Kotlin + WebView（`WebViewAssetLoader`，固定 https 來源，不開 file:// 存取）。
- `PetService`：`TYPE_APPLICATION_OVERLAY` + 前景服務（`specialUse`），通知列可隱藏、結束、開啟小島。
- `PetActor`：原生 Canvas 繪製，使用遊戲送來的同一套角色分層圖（含玩家匯入的圖片角色）；
  待機、走、跑、坐、睡、跳、**攀爬螢幕邊緣**、懸掛、掉落、被抱起甩出；上下滑動摸摸、點一下打招呼、點兩下開啟 App；
  多隻夥伴靠近會互相打招呼。每隻夥伴一個剛好包住角色的小視窗，其他區域的觸控直接交給底下的 App。
- 省電：螢幕關閉停止繪製；全部在睡覺時降為一半幀率；權限被撤銷自動停止；螢幕旋轉重新量測地面。
- 資料：桌寵互動寫入 `events.json`，主 App 回到前景時取回並寫進存檔；服務本身不模擬需求，避免重複計算。

### 驗證結果（Playwright，Chromium headless，390×844 手機尺寸）

- 新玩家流程：開場 → 跳過 → 選三隻示範夥伴 → 選房子 → 擺放 → 登場 → 新手引導 7 步（點擊、上下滑動摸摸、
  拖蘋果餵食、鏡頭、狀態卡、房子、地圖）→ 自由遊玩：通過，無 JS 錯誤。
- 3.2 舊存檔匯入：改名的示範角色、自創圖片角色（IndexedDB Blob）、星幣、目前操控角色、特質：全部正確；舊資料保留。
- 備份匯出 → 清除 → 匯入：角色、圖片、星幣一致。
- 40 倍速 AI 測試：角色會在家園、屋內、廣場、森林之間移動，出現拌嘴、安慰、跌倒、願望實現、技能升級等事件。
- 效能模式切換：Quality 60 FPS／Balanced 60 FPS／Battery 30 FPS 且渲染解析度確實降低，切換不需重新載入。

**APK 建置**：`./gradlew assembleDebug` 成功（AGP 8.7.3、Kotlin 2.0.21、compileSdk/targetSdk 35、minSdk 26），
已用 `aapt` 確認權限（SYSTEM_ALERT_WINDOW、FOREGROUND_SERVICE_SPECIAL_USE、POST_NOTIFICATIONS）、`specialUse` 前景服務與
內嵌的遊戲檔案。安裝檔：`dist/oc-shimeji-v4-debug.apk`（debug 簽章，可直接側載測試）。
GitHub Actions（`.github/workflows/android.yml`）每次推送會自動建置並上傳 APK。

另外以強制事件驗證：兩位愛吵架的角色大吵 → 出現「絕交」決定卡 → 選擇後關係變為「絕交」；感冒後喝熱湯縮短病程。

**未能實機驗證**：本環境沒有 Android 實機或模擬器，系統懸浮桌寵只完成編譯，尚未在實機上測試顯示於其他 App 上方、
觸控穿透、旋轉與鎖屏行為。請用 `android/` 專案安裝到手機測試，並回報問題。
